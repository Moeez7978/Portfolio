<h2>📐 Architecture &#x26; Infrastructure</h2>
<p align="center">
  <img src="https://raw.githubusercontent.com/acantril/aws-sa-associate-saac03/main/0700-SIMPLE_STORAGE_SERVICE(S3)/00_LEARNINGAIDS/S3AccessLogs.png" width="750"/>
</p>
<h3>Core Concepts</h3>
<table>
<thead>
<tr>
<th>Concept</th>
<th>Description</th>
</tr>
</thead>
<tbody>
<tr>
<td><strong>Bucket</strong></td>
<td>Top-level container for objects. Globally unique name, region-specific.</td>
</tr>
<tr>
<td><strong>Object</strong></td>
<td>The actual data stored (file + metadata). Max size <strong>5 TB</strong>.</td>
</tr>
<tr>
<td><strong>Key</strong></td>
<td>Unique identifier for an object within a bucket (full path).</td>
</tr>
<tr>
<td><strong>Region</strong></td>
<td>Buckets are created in a specific AWS region. Data does NOT leave the region unless you configure it.</td>
</tr>
<tr>
<td><strong>Namespace</strong></td>
<td>Global — bucket names must be unique across ALL AWS accounts.</td>
</tr>
</tbody>
</table>
<h3>Object Anatomy</h3>
<pre><code>s3://my-bucket/folder/subfolder/file.jpg
       │              │              │
    Bucket          Prefix          Key
</code></pre>
<ul>
<li>Object metadata: system metadata + user-defined metadata (key-value pairs)</li>
<li>Max object size via single PUT: <strong>5 GB</strong></li>
<li>For objects > 5 GB → <strong>Multipart Upload</strong> is required (recommended for > 100 MB)</li>
</ul>

<h2>🔐 Security</h2>
<p align="center">
  <img src="https://raw.githubusercontent.com/acantril/aws-sa-associate-saac03/main/0700-SIMPLE_STORAGE_SERVICE(S3)/00_LEARNINGAIDS/S3Security-2.png" width="750"/>
</p>
<h3>Access Control Layers</h3>
<pre><code>IAM Policies  →  Bucket Policies  →  ACLs  →  Block Public Access
</code></pre>
<table>
<thead>
<tr>
<th>Mechanism</th>
<th>Scope</th>
<th>Use Case</th>
</tr>
</thead>
<tbody>
<tr>
<td><strong>IAM Policies</strong></td>
<td>User/Role level</td>
<td>Control what AWS principals can do</td>
</tr>
<tr>
<td><strong>Bucket Policies</strong></td>
<td>Bucket/Object level (JSON)</td>
<td>Cross-account access, public access, enforce HTTPS</td>
</tr>
<tr>
<td><strong>ACLs</strong></td>
<td>Object/Bucket level</td>
<td>Legacy, mostly disabled by default now</td>
</tr>
<tr>
<td><strong>Block Public Access</strong></td>
<td>Account/Bucket level</td>
<td>Override all public grants — recommended ON</td>
</tr>
</tbody>
</table>
<h3>Bucket Policy Example — Enforce HTTPS</h3>
<pre><code class="language-json">{
  "Effect": "Deny",
  "Principal": "*",
  "Action": "s3:*",
  "Resource": "arn:aws:s3:::my-bucket/*",
  "Condition": {
    "Bool": { "aws:SecureTransport": "false" }
  }
}
</code></pre>

<th>Type</th>

<h2>🌐 Static Website Hosting</h2>
<p align="center">
  <img src="https://raw.githubusercontent.com/acantril/aws-sa-associate-saac03/main/0700-SIMPLE_STORAGE_SERVICE(S3)/00_LEARNINGAIDS/S3StaticHosting-1.png" width="750"/>
</p>
<h3>Setup Steps</h3>
<ol>
<li>Enable <strong>Static Website Hosting</strong> on the bucket</li>
<li>Set <strong>Index document</strong> (e.g., <code>index.html</code>) and <strong>Error document</strong> (e.g., <code>error.html</code>)</li>
<li>Disable <strong>Block Public Access</strong></li>
<li>Attach a <strong>Bucket Policy</strong> to allow <code>s3:GetObject</code> for <code>"Principal": "*"</code></li>
</ol>
<h3>Website Endpoint Format</h3>
<pre><code>http://&#x3C;bucket-name>.s3-website-&#x3C;region>.amazonaws.com
# or
http://&#x3C;bucket-name>.s3-website.&#x3C;region>.amazonaws.com
</code></pre>
<h3>CORS (Cross-Origin Resource Sharing)</h3>
<p>Required when a web app hosted on one domain fetches resources from an S3 bucket on another domain.</p>
<pre><code class="language-xml">&#x3C;CORSConfiguration>
  &#x3C;CORSRule>
    &#x3C;AllowedOrigin>https://myapp.com&#x3C;/AllowedOrigin>
    &#x3C;AllowedMethod>GET&#x3C;/AllowedMethod>
    &#x3C;AllowedHeader>*&#x3C;/AllowedHeader>
  &#x3C;/CORSRule>
&#x3C;/CORSConfiguration>
</code></pre>

<h2>🗂️ Versioning</h2>
<ul>
<li>Enabled at the <strong>bucket level</strong></li>
<li>Once enabled, can only be <strong>suspended</strong> (not disabled)</li>
<li>Each object version gets a unique <strong>Version ID</strong></li>
<li>Deleting an object adds a <strong>Delete Marker</strong> (doesn't permanently delete)</li>
<li>To permanently delete → specify the <strong>Version ID</strong></li>
</ul>
<h3>States</h3>
<pre><code>Unversioned  →  Versioning Enabled  →  Versioning Suspended
                      ↑_________________________________|
                      (can re-enable from suspended)
</code></pre>
<blockquote>
<p>💡 <strong>Exam Tip:</strong> Versioning protects against accidental deletes and overwrites. MFA Delete adds an extra layer requiring MFA to delete versions.</p>
</blockquote>
<h3>MFA Delete</h3>
<ul>
<li>Requires <strong>MFA</strong> to permanently delete object versions or change versioning state</li>
<li>Can only be enabled by the <strong>bucket owner (root account)</strong></li>
<li>Must be enabled via <strong>CLI</strong> (not console)</li>
</ul>
<hr>
<h2>🔒 Object Lock</h2>
<p>Implements <strong>WORM</strong> (Write Once Read Many) model. Prevents objects from being deleted or overwritten.</p>
<h3>Retention Modes</h3>
<table>
<thead>
<tr>
<th>Mode</th>
<th>Description</th>
</tr>
</thead>
<tbody>
<tr>
<td><strong>Compliance</strong></td>
<td>No one (including root) can delete/overwrite. Retention period cannot be shortened.</td>
</tr>
<tr>
<td><strong>Governance</strong></td>
<td>Users with special IAM permissions can override. Flexible for most use cases.</td>
</tr>
</tbody>
</table>
<h3>Legal Hold</h3>
<ul>
<li>Independent of retention period</li>
<li>Any user with <code>s3:PutObjectLegalHold</code> permission can place/remove it</li>
<li>Prevents deletion regardless of retention settings</li>
</ul>
<h3>Vault Lock (Glacier)</h3>
<ul>
<li>Similar to Object Lock but for <strong>S3 Glacier</strong></li>
<li>Policy is locked and <strong>cannot be changed</strong> once set</li>
<li>Used for compliance (HIPAA, SEC Rule 17a-4)</li>
</ul>

<h2>♻️ Lifecycle Policies</h2>
<p align="center">
  <img src="https://raw.githubusercontent.com/acantril/aws-sa-associate-saac03/main/0700-SIMPLE_STORAGE_SERVICE(S3)/00_LEARNINGAIDS/S3LifeCycle.png" width="750"/>
</p>
<p>Automate transitioning objects between storage classes or expiring them.</p>
<h3>Transition Actions</h3>
<pre><code>S3 Standard  →  Standard-IA / One Zone-IA  →  Glacier Instant  →  Glacier Flexible  →  Glacier Deep Archive
   (0 days)         (min 30 days)              (min 90 days)       (min 90 days)         (min 180 days)
</code></pre>
<h3>Expiration Actions</h3>
<ul>
<li>Delete objects after X days</li>
<li>Delete expired delete markers</li>
<li>Delete incomplete multipart uploads</li>
</ul>
<blockquote>
<p>💡 <strong>Exam Tip:</strong> Minimum 30 days in Standard before transitioning to Standard-IA or One Zone-IA.</p>
</blockquote>

<h2>⚡ Performance</h2>
<h3>Baseline</h3>
<ul>
<li><strong>3,500 PUT/COPY/POST/DELETE</strong> requests/sec per prefix</li>
<li><strong>5,500 GET/HEAD</strong> requests/sec per prefix</li>
<li>No limit on number of prefixes</li>
</ul>
<h3>Optimization Techniques</h3>
<table>
<thead>
<tr>
<th>Technique</th>
<th>Benefit</th>
</tr>
</thead>
<tbody>
<tr>
<td><strong>Multipart Upload</strong></td>
<td>Parallelize uploads, required > 5 GB</td>
</tr>
<tr>
<td><strong>S3 Transfer Acceleration</strong></td>
<td>Uses CloudFront edge locations for faster uploads</td>
</tr>
<tr>
<td><strong>Byte-Range Fetches</strong></td>
<td>Parallelize downloads, partial file retrieval</td>
</tr>
<tr>
<td><strong>S3 Select</strong></td>
<td>Retrieve subset of data using SQL (reduces data transfer)</td>
</tr>
<tr>
<td><strong>Prefix Spreading</strong></td>
<td>Distribute objects across multiple prefixes for higher throughput</td>
</tr>
</tbody>
</table>

<h2>🔗 Pre-Signed URLs</h2>
<p align="center">
  <img src="https://raw.githubusercontent.com/acantril/aws-sa-associate-saac03/main/0700-SIMPLE_STORAGE_SERVICE(S3)/00_LEARNINGAIDS/S3PresignedURL-1.png" width="750"/>
</p>
<p>Grant <strong>temporary access</strong> to private objects without changing bucket policy.</p>
<pre><code class="language-bash">aws s3 presign s3://my-bucket/my-file.jpg --expires-in 3600
</code></pre>
<ul>
<li>Default expiry: <strong>3600 seconds</strong> (1 hour)</li>
<li>Max expiry: <strong>7 days</strong> (using SDK), <strong>12 hours</strong> (using CLI)</li>
<li>Inherits permissions of the <strong>IAM user/role</strong> that generated it</li>
</ul>

<h2>🧰 Additional Features</h2>
<h3>S3 Select &#x26; Glacier Select</h3>
<p align="center">
  <img src="https://raw.githubusercontent.com/acantril/aws-sa-associate-saac03/main/0700-SIMPLE_STORAGE_SERVICE(S3)/00_LEARNINGAIDS/S3andGlacierSelect.png" width="750"/>
</p>
<ul>
<li>Retrieve subset of data using SQL on individual objects (CSV, JSON, Parquet)</li>
<li>Reduces data transfer and cost — filtering happens server-side</li>
</ul>
<h3>S3 Access Points</h3>
<ul>
<li>Simplify access management for shared datasets</li>
<li>Each access point has its own DNS name and policy</li>
<li>Can restrict access to specific VPCs</li>
</ul>
<h3>S3 Object Lambda</h3>
<ul>
<li>Transform objects on-the-fly as they are retrieved</li>
<li>Use cases: redact PII, convert formats, resize images</li>
<li>No need to store multiple versions of the same object</li>
</ul>
<h3>S3 Batch Operations</h3>
<ul>
<li>Perform bulk operations on billions of objects</li>
<li>Operations: Copy, Invoke Lambda, Restore, Tag, ACL, Object Lock</li>
<li>Uses a manifest (CSV or S3 Inventory report)</li>
</ul>
<h3>S3 Inventory</h3>
<ul>
<li>Audit and report on objects and their metadata</li>
<li>Output: CSV, ORC, or Parquet</li>
<li>Scheduled: daily or weekly</li>
</ul>
<h3>S3 Storage Lens</h3>
<ul>
<li>Organization-wide visibility into storage usage and activity</li>
<li>29+ usage and activity metrics</li>
<li>Interactive dashboard in the console</li>
</ul>
